# Agent Guidelines & Memory

## Automatic GitHub Synchronization
- Whenever tasks or modifications are performed in this repository, automatically commit and push the updated files to the GitHub remote repository (`origin/main`) without waiting for explicit instructions.
- Ensure all relevant assets, pages, and components are staged, committed with a concise and descriptive message, and pushed so that continuous deployment (e.g., Render) reflects the changes on the live website immediately.

## Design System & Theme Default (Crisp White Theme)
- Always use the **Crisp White Theme** by default for all UI components, sections, pages, and updates across the website.
- Do NOT use dark backgrounds (such as `bg-slate-950`, `bg-slate-900`, `bg-black`) for full sections or cards unless explicitly specified by the user.
- Adhere strictly to the enterprise design system: clean white backgrounds (`bg-white`), subtle off-white/slate card backgrounds (`bg-slate-50` or `bg-white`), crisp slate borders (`border-slate-200`), high-contrast slate text (`text-slate-950`, `text-slate-800`, `text-slate-600`), and clean blue/emerald/cyan accent badges and interactive states.
